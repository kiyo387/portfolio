# Shreyas Jayesh Bhavsar — Engineering Portfolio

> **B.Tech in Computer Science and Engineering (AIML) • RAIT Navi Mumbai (Batch 2025–2029, Semester III)**  
> Production-grade engineering portfolio built with React 19, Tailwind CSS v4, custom Three.js WebGL shaders, Lenis inertia scroll physics, and Framer Motion spring micro-interactions.

---

## ✨ Features & Architecture

- **Continuous 3D Spatial Scene**: Custom Three.js GLSL chromatic liquid mesh shader running at 60 FPS with responsive mouse deflection ripples and smooth scroll parallax.
- **Inertia Smooth Scroll**: Lenis inertial scrolling engine with spring-based navigation pill tracking and modal scroll isolation.
- **Projects Showcase**: Flagship interactive case studies including:
  - **ScholarBridge**: Centralized scholarship & academic mentorship discovery engine.
  - **RAIT Campus Navigator**: Geospatial Dijkstra and Euclidean $A^*$ shortest-path graph routing engine.
  - **Credit Card Fraud Detection**: Real-time transaction anomaly detection pipeline evaluated on PR-AUC.
- **Technical Skills**: Interactive category filtering across AI/ML, Low-Level Systems & Languages, Modern Web Engineering, and Computer Science Foundations.
- **Academic Timeline**: Chronological interactive journey from coding inception in procedural C (2025) to production web applications and applied ML models.
- **Direct Contact**: Verified communication channels (Personal Email, Institutional Email, LinkedIn, GitHub) with instant copy utilities.
- **Interactive CV Modal**: Built-in curriculum vitae drawer with quick-print formatting.

---

## 🛠️ Technology Stack

- **Core**: React 19, Vite, JavaScript (ESNext)

- **3D & Graphics**: Three.js, Custom GLSL Shaders

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node 20 / 24)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/kiyo387/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be running locally at `http://localhost:5173`.

### Production Build

```bash
npm run build
```

The production-optimized bundle will be emitted to `dist/`.
